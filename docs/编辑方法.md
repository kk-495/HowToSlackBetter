# 编辑方法与证据等级

## 性价比怎么理解

本指南里的“性价比”不把睡眠、尊严或他人的时间折算成分数。它帮助读者先看到个人成本、研究报告的收益和结论边界。成本与收益分开写；没有来源数据时，不编造节省百分比。

成本考虑金钱、时间、注意力/体力以及沟通负担。收益尽量报告研究设计、样本、结果指标和具体数值；研究没有测量的收益不补写成事实。

## 三十六计标题的用法

正文按六套、每套六条编排，沿用《三十六计》的计名作记忆索引和标题梗。计名不构成科学依据，也不要求读者照搬古代权谋；每条的行动描述、收益和证据等级都要由论文或官方资料直接支持。不得借标题鼓励欺瞒、甩锅、伪造状态或逃避职责。

## 六项条目格式

每条正文按参考指南的统一次序列出：

1. **成本**：金钱、时间、精力或沟通成本；估算不得伪装成实测数据。
2. **说人话**：将收益栏的研究结论转成日常语言；可用明确标注的假设情境或表达举例，帮助理解，但不添新数字，也不把例子写成来源验证过的效果。
3. **收益**：报告来源实际测量的对象、设计、样本和结果；数据不足时如实说明。
4. **证据等级**：仅使用 A 或 B。
5. **来源**：直接提供期刊论文或官方文件的完整引文和可点击链接。
6. **备注**：说明适用人群、研究局限、风险和不可外推事项。

## 证据等级

- **A**：有可核对的具体数据，来源为系统综述/荟萃分析、大型研究或随机试验。等级不代表结果对每个人都有效，也不自动意味着因果。
- **B**：有同行评审研究或官方资料直接支持，但样本、设计、测量或适用场景有限，或来源只支持结论的一部分。

正文不设作者经验等级。为扩展条目的可读性而加入的原创情境、话术或工作流程，应明确标成例子；收益栏只陈述来源直接支持的结论，备注说明示例做法是否未经单独验证。不能用宽泛研究给未经验证的具体做法背书。

## 来源使用规则

1. 优先引用期刊论文原文、论文摘要或官方机构文件，并让来源链接直达原始记录。
2. 只写来源实际支持的句子；观察相关不写成因果，未测量的效果不推算。
3. 标明研究设计、样本、关键结果和适用限制。未核实的数字不收录。
4. 重要事实变化时更新核实日期，并在更新记录中说明变更。
5. 纠错优先于增加条目数量；证据不足时删去或改成来源直接支持的事实描述。

## 范围

指南面向一般办公室和知识工作场景，讨论工作边界、注意力、会议、恢复、协作、工作设计和工作环境。不提供规避职责、伪造考勤、逃避值班、钻法律空子或转嫁负担的方法。法律、工时、安全与医疗问题按所在地现行官方规定及专业意见处理。
