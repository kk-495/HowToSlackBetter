# 编辑方法与证据等级

## 性价比怎么理解

本指南里的“性价比”不是把睡眠、尊严或他人的时间折算成分数。它只帮助读者先挑**个人成本较低、潜在收益可说清、风险不转嫁他人**的做法。成本和收益分开写，避免用一个看似精确的总分遮住价值取舍。

每条成本考虑四项：金钱、时间、注意力/体力、沟通或关系成本。每条收益写可能减少的返工、等待、切换、疲劳或下班后侵占。没有数据就不填节省百分比。

## 证据等级

- **A**：针对该主张的系统综述/荟萃分析、随机对照试验或大样本多场景证据。明确实验人群、结果指标和不确定性。
- **B**：一项或少量同行评审研究、准实验、观察研究，或有明确范围的官方资料。只能支持有限场景或建议中的一部分。
- **C**：本指南作者的操作建议、沟通模板或工作流假设，没有直接研究证明该具体做法一定有效。

等级不表示“建议强制做”的程度。A 级研究也可能来自特定岗位，不能外推到所有行业。研究里的平均结果不能预测单个员工的表现。

## 来源使用规则

1. 尽量引用论文原文、官方机构资料或数据，而非媒体转述。
2. 来源只支持明确能支持的句子；对沟通模板或流程建议标 C，不借研究给它镀金。
3. 标清研究设计、样本与关键限制。观察相关不写成因果。
4. 重要事实变化时更新核实日期，并在更新记录里写清变更。
5. 纠错优先于扩充条目数量。不能可靠核实的数字不收录。

## 范围

指南面向一般办公室/知识工作场景，优先谈工作设计和沟通，不提供规避雇主义务、伪造考勤、逃避值班、钻法律空子或压榨同事的方法。法律、工时、安全与医疗问题按当地现行官方规定及专业意见处理。
