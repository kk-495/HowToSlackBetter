# 高性价比摸鱼指南

**把该交付的交付好，把不必消耗的精力省下来。**

这是一份关于工作边界、注意力、会议、休息和协作的实用清单。这里说的“摸鱼”，不是失联、造假、甩锅或把工作塞给同事，而是在履行明确职责的前提下，减少低价值忙碌，让时间和精力回到真正重要的事情上。

目前共 **90 条有研究或官方资料支持的建议、22 个主题章节、56 项期刊研究与官方来源**。每条统一列出成本、说人话、收益、证据等级、原始来源和备注；不收录没有直接依据的作者经验条目。研究数据和适用范围另见[证据数据台账](docs/证据数据台账.md)。

本指南的组织方式受到 [《高性价比人生指南》](https://github.com/eternity4719/HowToLiveBetter) 的启发：按问题分章，把建议拆成小条目，写清成本、收益、证据强弱和来源。正文、例子和表达均为本项目原创；项目与原作者无隶属或背书关系，不复制原书条目、数据或段落。

**不用全做。** 这是一份备选清单，不是新的待办清单。挑一两条试一周，没用就放下。休息不是需要优化到极致的生产资料。

## 怎么读每一条

每条建议按固定六项编排：成本、说人话、收益、证据等级、来源、备注。成本写金钱、时间、精力或沟通负担；“说人话”只转述收益栏已写出的结论；收益尽量写研究设计、样本和结果；备注交代适用边界。研究平均结果不保证对每个人都成立。

| 等级 | 含义 |
| --- | --- |
| **A** | 有可核对的具体数据，来源为荟萃分析、系统综述、大型研究或随机试验。仍须按样本和场景理解，不能保证个体效果。 |
| **B** | 有同行评审论文或官方资料直接支持，但样本、设计或适用场景有限，或来源只支持结论的一部分。 |

证据等级评价的是**条目所说的那件事**。每条“来源”直接链接期刊论文或官方文件；完整书目信息、设计和范围见[来源与核实记录](docs/来源与核实记录.md)。研究发现“关联”时，不把它改写成“必然导致”；来自单一公司、单一行业或短期实验的结论会明确标出。

## 这套清单的边界

1. **约定先于技巧**：岗位职责、明确期限、值班响应、安全规程和团队已承诺的协作必须优先。
2. **只省自己的无效成本**：不伪造工时、状态、故障或进度；不把风险和工作量悄悄转嫁给别人。
3. **把冲突摆到台面上**：时间不够时说明取舍，请负责人定优先级，不用深夜加班掩盖容量问题。
4. **不拿健康换在线时长**：本指南不是医疗或法律意见，也不鼓励突破当地工时、安全或休息要求。
5. **高风险岗位以安全为先**：医疗、交通、生产、安保、客服值守等岗位，需要持续响应时必须遵循岗位制度和法规。

长期超负荷、被要求隐瞒风险或无法休息，通常不是个人“摸鱼技巧”能解决的问题。记录事实，使用组织认可的求助、工会/员工代表、人力资源或当地劳动咨询渠道。地区规定会变化，涉及权益时查当地官方来源。

## 一周试读法

| 日程 | 只做一件小事 |
| --- | --- |
| 周一 | 把一项任务的目标、期限和验收标准问清楚。 |
| 周二 | 找一个非紧急提醒，改成集中查看。 |
| 周三 | 让一个会议有议程、结束时间和行动项。 |
| 周四 | 对一个新增请求说明它会挤占哪件已承诺的工作。 |
| 周五 | 看哪项真的减少了返工或疲劳；保留有用的，删掉没用的。 |
